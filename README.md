A token launch radar that ranks pre-token DeFi protocols by calibrated implied value, with farm plans and a static dashboard. It reads a sealed snapshot of 758 protocols, calibrates sector multiples from the protocols whose tokens already trade, and hands in a ranked board of 198 protocols with concrete steps to farm each one. Entry for make.fun's token-radar-01 bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
